Servidor en línea

Servidor Linux de Alberto Cuesta

Un servidor Ubuntu en AWS, montado y asegurado a mano como proyecto de sistemas.

🐧

Sistema

Ubuntu Server 26.04 LTS en una instancia EC2 t3.micro, región Irlanda.

🌐

Servidor web

nginx en el puerto 80, con CloudFront delante para servir esta página por HTTPS.

🛡️

Firewall

Grupo de seguridad de AWS y UFW dentro del servidor. Solo están abiertos SSH y HTTP.

🔑

Acceso

SSH solo con clave. Sin contraseñas, y root no puede entrar con contraseña.

👤

Usuarios

Usuario diario sin permisos de administrador, con el principio de mínimo privilegio.

🔄

Actualizado

Paquetes y parches de seguridad al día.
