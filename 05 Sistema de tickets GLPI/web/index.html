Proyecto · Soporte IT Probado en local

Sistema de tickets GLPI

Un Help Desk montado desde cero en una máquina virtual Ubuntu: entidades, categorías, usuarios, tickets y guías de resolución de problemas.

Todos los datos son de ejemplo: las entidades, los usuarios y los tickets son ficticios y llevan la marca "[EJEMPLO]". Coste: 0 €.

🖥️

Máquina virtual

VirtualBox con Ubuntu Server 26.04.1 LTS: 2 GB de RAM, 1 CPU y 20 GB de disco.

⚙️

Servidor

Apache 2.4.66, MariaDB 11.8.6 y PHP 8.5.4 con las extensiones que pide GLPI.

🎫

GLPI 12.0.1

Instalado desde la consola, con base de datos y usuario de base de datos propios.

🏢

Organización

3 entidades (Empresa Demo, Sede Madrid y Sede Barcelona) y 6 categorías.

👥

Usuarios y perfiles

5 usuarios ficticios sin contraseña, con los perfiles de GLPI: Self-Service, Hotliner y Technician.

📚

Guías

4 guías en la base de conocimiento: impresora, VPN, contraseña olvidada y equipo lento.

8 tickets de ejemplo

En todos los estados: nuevo, en curso, en espera, resuelto y cerrado. Con seguimiento y solución.
